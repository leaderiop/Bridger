02 · Decisions to make first

These need the spec owner's call. Each lists a recommended option and the main alternative.

D1How long may a sub-scope close or unmount wait for a stop the parent already started?

Closes
H1, C10
Recommended
Follow the parent stop's own limits: park with the operator call, wait for the overall limit under shutdown, revoke only on a path with no caller.
Alternative
Keep drainTimeout and revocation, and add sub-scope close and unmount to the paths with no caller in BEH-BR-086 and INV-BR-017. This lets a finalizer override an operator's force: false.

D2How does a subagent learn that its parent took its draft?

Closes
H2, T2
Recommended
A hand-off marker on the cancel, for example Tasks.cancel(taskId, ctx, { handedDraftId }), set by spawnSubagent only for the subagent whose draft the parent took.
Alternative
A callback on SpawnStart that the subagent's loop consults before it withdraws. This adds a second channel between the loops.

D3How does the bus know when a fenced transaction has ended?

Closes
H3, F4
Recommended
A scoped fence: it requires Scope, and its finalizer runs when the adapter's transaction ends. Setting the freeze refuses new fences first, then waits for the open ones.
Alternative
An adapter obligation: a freeze row that transaction reads, serialised with open writers. This puts more work in every storage adapter.

D4Where does a federation link get its TransportProfile?

Closes
H4, F1
Recommended
LinkDialer.dial and LinkListener.accept yield { connection, profile }, which BEH-FD-017 passes to both multiplex calls.
Alternative
A profile field on the link configuration per peer. This is simpler, but the profile can drift from the real transport.

D5How are plugins named in HeldPlugins, CurrentTransition and WouldDeadlock?

Closes
C1
Recommended
A canonical realm/id string, so the reference types stay string and the error gains realm.
Alternative
A { id, realm } record. Clearer, but it changes the exported reference types (CCR-BR-020).

D6What does Entitlement.guard trust?

Closes
E1, E2, E3
Recommended
The passed entitled stream only, with pluginId from the runtime, an application-wide essential list from Entitlement.layer, and a checkTimeout that yields NotEntitled "unknown".
Alternative
Keep the fiber principal and narrow INV-EN-005. Smaller, but provided methods stay unguarded for application callers.
